02 / WORKFLOW

新品开发的六个关口

每一关都有明确的「过不去就不能往下走」的判据。卡住就回上一关改，不要带着问题往前走。

STEP 01趋势判断

近90 天新品ASIN 增速、评论里反复出现的抱怨，就是需求缺口。

STEP 02产品定义

规格表定死核心参数与反参数（明确不做什么）。

STEP 03成本前置

报价未出前先用行业区间算毛利能不能成立，成立才立项。

STEP 04打样

结构、材质、公差、装配顺序四项一起验，不只看外观。

STEP 05量产

产线走通、包装抗压测试、备件与说明书定稿。

STEP 06上市验证

AMZ/TK 双渠道上架，按周看动销与盈亏，48小时定去留。

📐 利润测算 Prompt

输入成本与箱规，输出多渠道分项利润与盈亏平衡点。强制要求尺寸数据来自实时查件，不许用本地参考值。

# 角色
跨境产品利润分析师。
# 输入
产品成本、箱规尺寸(实时查得)、目标售价。
# 硬性要求
1. 尺寸/重量必须来自卖家精灵实时数据，
   禁止使用本地参考值
2. 分渠道列出: 采购/包装/头程/佣金/税
3. 输出单件净利、净利率、盈亏平衡销量
4. 每一步给公式，不给结论
PROMPT

🔍 趋势选品 Prompt

用ASIN 级数据找类目空位：谁在涨、涨得有多陡、供给还没跟上。

# 目标
从核心类目中筛出≥3 款趋势新品。
# 方法
1. 取近两个窗口的 ASIN 级销量
2. 新进入者定义(注意):
   前窗口销量=0 且 当前窗口有销量
   = 按 listing 维度, 不按品牌
3. 输出: ASIN / 品类 / 增速 / 均价 / 卖家数
4. 卖家数少 + 增速高 = 空位

✅ 打样验收清单

样品到手当天逐项过，任一项不过就退回重做，不进量产。

□ 结构：拆解后每个件都能独立拿取

🗂 数据分析口径

几个容易算错的定义，先对齐再动手。

新进入者 = 前窗口0 且 当前窗口有量(按ASIN)
净利   = 售价 − 采购 − 包装 − 头程
              − 佣金 − 税
盈亏平衡 = 固定投入 ÷ 单件净利
销量估算 = 按目标价位档, 不用实际挂牌价
注意   = 低价是引流款, 不代表主推款

06 / FAQ

常见问题

这些资源可以直接用在你自己的项目上吗？

可以。都是纯文本模板，粘走就能用。唯一要求：尺寸重量这类数据请自己去查实时值，我这里给的是方法和口径，不是缓存数字。

为什么不放具体项目的敏感数据？

利润表、供应商报价、销量明细属于原东家数据。分享的是判断逻辑和表格结构，具体数字请用你自己的项目重跑。

「外观是最后一道」是什么意思？

意思是先确认能量产，再谈好不好看。画得出来但装不进去、公差控不住、模具做不了的工业设计，对产品没有价值。工业设计背景让我习惯从可制造性倒推造型。

新进入者为什么按 ASIN 算不按品牌？

因为趋势机会藏在具体listing 上。一个老品牌新推一个ASIN，和一个从零起来的新品牌，在数据上长得完全不一样。按品牌算会把最有意思的信号抹掉。

技能站和求职站有什么区别？

求职站讲的是「我是谁、做成过什么」，用叙事和案例。这站讲的是「怎么做的」，可以直接抄走。如果你在面试里被追问方法细节，看这站。

想聊具体的品类？

我更愿意聊具体的品、具体的数据和具体的坑，而不是泛泛的方法论。手上正在看的方向：家电、工具五金、花园户外、水上泳池。宠物类也能做，但需要从零补。
