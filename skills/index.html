SIX GATES新品开发的六个关口

每一关都有明确的「过不去就不能往下走」的判据。卡住就回上一关改，不要带着问题往前走。

01趋势判断　近 90 天新品 ASIN 增速、评论里反复出现的抱怨，就是需求缺口。没有数据支撑的「我觉得」，不进下一关。
02产品定义　规格表定死核心参数与反参数（明确不做什么）。反参数比参数更能防止后面无限加需求。
03成本前置　报价未出前先用行业区间算毛利能不能成立，成立才立项。不成立的项目，做得再漂亮也是负债。
04打样验证　结构、材质、公差、装配顺序四项一起验，不只看外观。任一项不过就退回，不带问题进量产。
05量产确认　产线走通、包装抗压、备件与说明书定稿。这一步出问题，前面所有工作都白做。
06上市验证　AMZ / TK 双渠道上架，按周看动销与盈亏，48 小时定去留。不动销就回滚，不硬撑。

STRUCTURE把结构问题变成可交付的规格

设计背景转产品，最大的红利是能跟结构工程师用同一套语言吵。两个例子：压紧力的反向核算，和静密封选型。

CASE 01 · 压紧

圆角矩形不是四个直角

  • 周长按 P = 4(L−2Rc) + 2πRc 算，不能用 4L——一次算错，所有压强结论全错
  • 压紧几何分两种：转角弧段也压（P_eff = P − 8e）与不压（P_eff = 4(L−2Rc) − 8e）
  • 压痕宽度 w = 2√(2Rh−h²)；压强 p = F/(w·P_eff)×1000 kPa
  • 反向约束：F ≤ (A − mg)/μ——先算约束边界，再定参数，不倒过来

CASE 02 · 密封

「型号不对」是必然，不是意外

  • 压缩率 squeeze = (d−h)/d，静密封要求 15%~25%，GB/T 3452.1 上限 30%
  • 沟槽深 h 开模后改不了，只能选线径 d；可行窗口 d ∈ [h/0.85, h/0.75] 只有约 13% 宽
  • 窗口窄到这个程度，供应商「选错型号」几乎必然——所以要给现场一张三个数的排查卡，而不是一句「按标准选」

PROMPT 01

利润测算

输入产品成本与箱规，输出多渠道分项利润与盈亏平衡点。硬性要求：尺寸重量必须实时查得，不许用本地参考值。

角色＝跨境产品利润分析师
输出＝采购/包装/头程/佣金/税 分项 + 单件净利 + 盈亏平衡销量
要求＝每一步给公式，不给结论

PROMPT 02

趋势选品

用 ASIN 级数据找类目空位：谁在涨、涨得多陡、供给还没跟上。

新进入者定义＝前窗口销量 0、当前窗口有销量
维度＝listing，不按品牌
判据＝卖家数少 + 增速高 = 空位
